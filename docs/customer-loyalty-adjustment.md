# Корректировка из карточки клиента

Совместимое расширение существующего POST /api/customers/:id/loyalty-adjustment: targetBalance, expectedBalance, consentVersion и requestId. Прежние клиенты с дельтами остаются совместимыми. Авторизация устройства и администратора сохранена. Новая ветка работает в транзакции с privacy-блокировкой и блокировкой программы, проверяет статус участия и исходный баланс. Повтор ключа возвращает подтверждение без новой записи; другой целевой баланс с прежним ключом отклоняется. В журнале сохраняются причина, администратор и исходное/целевое состояния. Новая миграция не требуется.

В membership API добавлено уже имеющееся consented_at для отображения даты согласия. Подключение, сроки хранения и прекращение участия не изменялись. Backend npm test: 139/139. Дополнительные проверки Flyway и развёртывания выполняются Actions. Реальные клиентские балансы вручную не менялись.
