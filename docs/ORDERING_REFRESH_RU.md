# Цикл обновления онлайн-заказа — 08.10.2026

База backend: 494e0ba. Публичный /api/config подтвердил orderingOpen=false и часы Europe/Minsk 10:00–22:30; live root отдавал интерфейс с applyOrderingState → location.reload при закрытом состоянии. После получения config загрузка повторялась, и страница снова перезагружалась. Это клиентский цикл, не сбой Telegram или POS SSE. Расписание приёма заказов не изменено.

applyOrderingState больше не выполняет навигацию: закрытое состояние отключает оформление и показывает часы, сохраняя корзину и поля. Подтверждённый boolean orderingOpen сервера имеет приоритет перед локальными часами; локальное время — только fallback до первого валидного config. Config обновляется раз в минуту, при возврате во вкладку и у границы закрытия; запрос single-flight с timeout 10 секунд, cache no-store. Сбой запроса сохраняет последнее подтверждённое состояние. Сервер по-прежнему окончательно проверяет часы при checkout.

Пока checkout выполняется, обновление статуса не включает кнопку повторно и не заменяет progress. Временная closed page также проверяет /api/config, а не только часы телефона, и запрашивает reload максимум один раз после server orderingOpen=true. Это исключает повторную перезагрузку при несовпадении часов браузера/сервера.

Добавлены 4 regression tests: многократный closed state без reload; приоритет серверного состояния над временем и offline; pending checkout не включается обновлением; closed page reload только после server confirmation и один раз. Старый тест, требовавший reload в 22:30, обновлён на сохранение вкладки с disabled checkout; VM fixture получает AbortController. Local tests не запускались; только syntax/diff. Приёмка после деплоя: страница стабильна без непрерывных document requests; при orderingOpen=true заказ доступен, после закрытия кнопка отключена без потери формы; при возвращении во вкладку статус обновляется. Вне 10:00–22:30 невозможность оформить заказ соответствует расписанию. Деплой Railway и физическая проверка браузера pending до наблюдения новой версии.
